# Pydough Error Classification System

This system provides a dual approach to classifying error messages using both regex pattern matching and LLM-based classification. It helps categorize errors into specific subclasses and main classes, making it easier to understand and debug issues.

## Overview

The classification system uses two methods in parallel:

1. **Regex-based Classification**: Uses predefined patterns to quickly categorize errors
2. **LLM-based Classification**: Uses Google's Gemini model to provide more nuanced classification with explanations

## How It Works

### Regex Classification
The system maintains a list of predefined patterns (`CLASS_PATTERNS`) that match specific error types. These patterns are applied in order, with the first match determining the classification. The patterns are designed to catch common error messages and categorize them into specific subclasses.

### LLM Classification
The system uses Google's Gemini model to analyze error messages and provide:
- Subclass classification
- Confidence score
- Explanation for the classification

The LLM is provided with a reference dataset of error subclasses and their descriptions to make informed decisions.

## Pydough Error Classes and Subclasses

The system uses a hierarchical classification system:
- **Main Classes**: Broad categories of errors
- **Subclasses**: More specific error types within each main class

The reference data for these classifications is stored in two key files:

1. `sample_data/error_classes_with_desc_and_examples.csv`
   - Contains detailed descriptions of main error classes
   - Includes example error messages for each class
   - Helps understand the broad categories of errors

2. `sample_data/error_subclass_with_main_classes.csv`
   - Maps subclasses to their parent main classes
   - Contains descriptions of what each subclass means
   - Provides guidance on typical next steps for each error type

## Usage

```bash
python classify_errors.py input.csv [output.csv] [--limit N]
```

### Arguments:
- `input.csv`: Input file containing error messages
- `output.csv`: (Optional) Output file for classification results
- `--limit N`: (Optional) Limit the number of examples to process

### Output
The script generates:
1. A CSV file with classification results
2. A classification report comparing regex vs LLM classifications
3. A confusion matrix visualization

## Understanding Error Classes

To learn more about the error classes and subclasses:

1. Review the main error classes in `sample_data/error_classes_with_desc_and_examples.csv`
   - This file provides comprehensive descriptions and examples
   - Helps understand the root causes of different error types

2. Check the subclasses in `sample_data/error_subclass_with_main_classes.csv`
   - Shows how specific error types map to broader categories
   - Includes guidance on resolving each type of error

3. Review the regex patterns in `CLASS_PATTERNS` to understand how errors are matched
4. Look at the classification reports and confusion matrices generated by the script


   ```bash

   ```
